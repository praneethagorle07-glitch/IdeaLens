# 🚀 IdeaLens

### AI-Powered Project Discovery, Evaluation & Career Guidance

IdeaLens is an AI-powered web application that helps students and aspiring AI/ML engineers discover, evaluate, and compare project ideas based on their career goals, experience level, and existing skills.

It uses Generative AI to provide personalized project evaluations, skill-gap analysis, learning recommendations, and career-focused guidance.

---

## 🌟 Features

### 🤖 AI-Powered Project Analysis

Describe a project idea and provide your career goal, experience level, and current skills.

IdeaLens generates:

- Project overview
- Problem being solved
- Innovation score
- Impact score
- Feasibility score
- Technical depth score
- Resume value score
- Overall evaluation
- Skill-gap analysis
- Recommended features
- Alternative project ideas
- Potential challenges
- Suggestions for improvement

---

### ⚖️ Compare Two Project Ideas

IdeaLens allows users to compare two different project ideas using AI.

Projects are evaluated across:

- Innovation
- Impact
- Feasibility
- Technical Depth
- Resume Value
- Overall Score

The application then recommends the stronger project based on the evaluation.

---

### 🧩 Skill-Gap Analysis

IdeaLens identifies additional skills that may be required to successfully build a project.

Examples include:

- MLOps & Deployment
- System Design & Architecture
- NLP / LLM Application Design
- Frontend Development

Skills are categorized by priority to help users understand what they should learn next.

---

### 💡 Personalized Recommendations

The application provides recommendations tailored to the user's:

- Target career
- Experience level
- Current technical skills
- Project idea

This helps users choose projects that are both technically meaningful and valuable for their portfolio.

---

## 🎯 Target Users

IdeaLens is designed for:

- Students

- Aspiring AI/ML Engineers
- Data Science students
- Developers building their portfolios
- Candidates preparing for internships and entry-level roles
